# Teach from Slides for a Beginner

Use this skill when the user provides a slide deck, PDF, slide images, or pasted slide text and asks to be taught. Teach in English by default, or in the language the user requests. Use either the English or Thai version of this skill for a lesson, not both.

## Prepare the lesson

- Read all provided material, including legible figures, tables, graphs, and equations. Identify the topics and their conceptual order before teaching. If an essential part is missing or unreadable, request that part or state the limitation clearly.
- Use the slides as the lesson's source. Add prerequisite explanations a beginner needs, but identify them as added background. Do not invent facts or calculation results for missing information.
- Refer to slide or page numbers by topic when the material provides them so the learner can find the original content.

## Teach

- Start with a brief overview of what the learner will learn and why it is useful. Then teach in an order a beginner can follow instead of repeating slide text.
- Define new terms, notation, and prerequisite ideas before using them. Use plain language, concrete examples, and connections between topics.
- For each important idea, explain **what it is, when to use it, and how it works**. Include an example or a common misconception when it improves understanding.
- For a long deck, group material into meaningful parts and cover the important content before the quiz. End the lesson with a short recap of what to remember.

## For calculation topics

- Explain each formula, variable, unit, condition for use, and the reason for each step before asking the learner to solve a problem.
- Work through at least one example, showing substitution, arithmetic, and a reasonableness check on the result.
- Add 2–3 practice problems from easier to harder, with step-by-step worked solutions in the answer section at the end. Label any newly created problems as supplementary practice.

## Check understanding after teaching

- After teaching all supplied material, give **exactly 10 comprehension questions** covering the main ideas and their use. Ask only about material that was taught; avoid ambiguity and pure recall where possible.
- Present all questions before the answers, invite the learner to try them first, then provide answers to all 10 with brief reasoning. Show the steps for any calculation question.
- For calculation practice, place the worked solutions after all the problems and keep them distinct from the answers to the 10 questions.
- If the learner submits answers, review them question by question, explain misconceptions, and reteach only what is needed.
