# Skills

แต่ละสกิลมีเวอร์ชันภาษาไทย (`-th`) และภาษาอังกฤษ (`-en`) เลือกใช้เวอร์ชันเดียวต่อหนึ่งงาน

| สกิล | ใช้ทำอะไร |
| --- | --- |
| `sorawit-coding-th` / `sorawit-coding-en` | เขียนโค้ดตามรูปแบบงานนักศึกษาและทดสอบจริง |
| `junior-dev-workflow-th` / `junior-dev-workflow-en` | ทำงานโค้ดเป็นขั้นตอน พร้อม checkpoint และ Git commit |
| `slide-tutor-th` / `slide-tutor-en` | สอนจากสไลด์สำหรับผู้เริ่มต้น ถามความเข้าใจ 10 ข้อ และให้โจทย์คำนวณพร้อมเฉลยเมื่อเกี่ยวข้อง |

## วิธีใช้

คัดลอก `SKILL.md` จากโฟลเดอร์ที่ต้องการไปไว้ที่ `C:\Users\<ชื่อผู้ใช้>\.codex\skills\<ชื่อสกิล>\SKILL.md` โดยใช้ชื่อสกิลจากตารางเป็นชื่อโฟลเดอร์ปลายทาง แล้วเรียกในคำสั่ง เช่น `ใช้ $slide-tutor-th สอนจากสไลด์ที่แนบมา`
