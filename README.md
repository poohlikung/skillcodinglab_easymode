# คู่มือใช้ Coding Skills

โปรเจกต์นี้มี 2 แนวทาง แต่ละแนวทางมีเวอร์ชันภาษาไทย (`-th`) และอังกฤษ (`-en`) ที่ให้กติกาเดียวกัน เลือกใช้ภาษาใดภาษาหนึ่งต่อแนวทาง

| โฟลเดอร์ในโปรเจกต์ | ชื่อ skill ที่ใช้เรียก |
| --- | --- |
| `skillทำlab_sorawit-coding-th` / `skillทำlab_sorawit-coding-en` | `$sorawit-coding-th` / `$sorawit-coding-en` |
| `skillโปรเจคjunior-dev-workflow-th` / `skillโปรเจคjunior-dev-workflow-en` | `$junior-dev-workflow-th` / `$junior-dev-workflow-en` |

| Skill | คำอธิบายสั้น ๆ | จุดต่างที่สำคัญ |
| --- | --- | --- |
| `sorawit-coding-th` / `sorawit-coding-en` | เขียนหรือแก้โค้ดตามรูปแบบงานนักศึกษา พร้อมตรวจการทำงานจริง | ใส่หัวคอมเมนต์ชื่อและรหัสนักศึกษาในไฟล์โค้ด ห้ามเพิ่มคอมเมนต์อธิบายอื่น จัดรูปแบบโค้ดทุกไฟล์ที่แก้ และลบเฉพาะไฟล์ทดสอบที่สร้างระหว่างงานหลังตรวจผลแล้ว |
| `junior-dev-workflow-th` / `junior-dev-workflow-en` | ทำงานโค้ดเป็นขั้นตอนเพื่อให้คนหรือ AI ทำต่อได้ง่าย | เขียนคอมเมนต์อธิบายที่จำเป็นเป็นภาษาไทย ตรวจผลจริง บันทึก `AI_CHECKPOINT.md` ภาษาไทย และแบ่ง Git commit ตามส่วนงาน |

ทั้งสองแนวทางให้จัดไฟล์ตามหน้าที่เมื่อช่วยให้อ่านง่าย โดยไม่บังคับแยกงานที่เหมาะกับไฟล์เดียว และให้ตรวจการทำงานตามความเหมาะสม

## วิธีใช้

1. เลือกโฟลเดอร์จากตาราง แล้วคัดลอก `SKILL.md` ไปไว้ที่ `C:\Users\<ชื่อผู้ใช้>\.codex\skills\<ชื่อ skill>\SKILL.md` โดยใช้ชื่อ skill จากคอลัมน์ขวา (ไม่ใส่ `$`)
2. ระบุชื่อ skill ในคำสั่งที่ส่งให้ Codex เช่น `ใช้ $sorawit-coding-th แก้ฟังก์ชันคำนวณราคา` หรือ `ใช้ $junior-dev-workflow-th เพิ่มหน้าค้นหา`
3. เลือกเวอร์ชัน `-en` แทน `-th` เมื่อต้องการอ่านคำสั่ง skill เป็นภาษาอังกฤษ

ควรเลือกใช้หนึ่งแนวทางต่อหนึ่งงาน เพราะกติกาคอมเมนต์ต่างกัน: `sorawit-coding` ห้ามเพิ่มคอมเมนต์อธิบาย แต่ `junior-dev-workflow` ให้เขียนคอมเมนต์ภาษาไทยเมื่อจำเป็น
